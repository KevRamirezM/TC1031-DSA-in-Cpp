# Computational Complexity

Measure of the amount of computing resources, such as time and memory, that an algorithm requires to run as a function of the input size.

## P Problems

These are problems that can be solved and verified in polynomial time. This is a complexity class.

Some examples of this types of problems in Big O notation are:

- O(n)
- O(n^2)
- O(n^3)

## NP Problems (Nondeterministic Polynomial)

These are problems that can be verified in polynomial time but may be difficult to solve (for a computer). P is a subclass of NP. This is a complexity class.

Some examples of this types of problems in Big O notation are:

- O(2^n)
- O(n!)
- O(n^k)

## NP-Hard Problems

These are problems that are at least as hard as the hardest problems in NP. If a polynomial-time algorithm exists for any NP-hard problem, then all problems in NP can be solved in polynomial time. This is a complexity class.

## NP-Complete Problems

These are problems that are both NP and NP-hard. If a polynomial-time algorithm exists for any NP-complete problem, then all problems in NP can be solved in polynomial time. They are the hardest problems in NP. This is a complexity class.
